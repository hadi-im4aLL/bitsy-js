Quick start

Build a scoreboard that displays a list of players and updates when you add a point. You'll write the HTML, set up the data, and call run().

1. Write the markup#

Save the markup below in an HTML page. The title uses a placeholder, b-if checks for an empty list, and b-for renders one row per player. 

<div b-data>
    <h1>{title()}</h1>
    <p>Total score: {total()}</p>

    <p b-if="players().length === 0">No players yet.</p>

    <ul>
        <li b-for="player of players()">
            {player.name} - {player.score} points
            <button b-on:click="addPoint(player.id)">+1</button>
        </li>
    </ul>
</div>

The bare b-data attribute gives placeholders a scope backed by the constructor's data. Directives such as b-for and b-if can read that global data without the wrapper.

2. Describe the data#

Save the JavaScript below as app.js next to the HTML file and a local copy of bitsy.min.js. You can also replace the import path with the CDN URL from the installation guide. The constructor's data option makes the signals and addPoint available to the markup. 

import { BitsyJS, computed, signal } from "./bitsy.min.js";

const title = signal("Scoreboard");
const players = signal([
    { id: 1, name: "Alpha", score: 10 },
    { id: 2, name: "Beta", score: 7 },
]);

const total = computed(() => players().reduce((sum, player) => sum + player.score, 0));

const addPoint = (id) => {
    players.update((list) => list.map((player) => (player.id === id ? { ...player, score: player.score + 1 } : player)));
};

const bitsy = new BitsyJS({
    data: { title, players, total, addPoint },
});

Read a signal by calling it, as in {title()}. Use players.update() to calculate the next list. Return a new array instead of mutating the existing one in place. A signal uses Object.is to check whether its value changed.

3. Call run()#

Append this code to app.js. Load it from the HTML with <script type="module" src="./app.js"></script> and open the page through a local HTTP server. Register ready() before run() if you want a callback when the initial render finishes. 

bitsy.ready(() => {
    console.log("rendered");
});

await bitsy.run();
Try it: You should see Alpha and Beta. Click +1 next to either player to increase that player's score. Inspect the rendered list to see the generated rows without the original b-for attribute.

4. Add interactivity#

The scoreboard's b-on:click handler uses the current loop item to pass the right player.id to addPoint(). To react to typing instead, use b-on:input. Its $event variable is the DOM event, and $el is the element with the handler. 

<input
    type="text"
    value="{name()}"
    b-on:input="name.set($event.target.value)"
/>

<p>Hello, {name()}</p>

To try this snippet, add name: signal("") to the constructor's data and place both elements inside the b-data wrapper.
