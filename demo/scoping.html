Scope rules

  • Global config data is the base for every b-data scope.
  • Local keys override global keys for that scope only.
  • Keep b-data scopes as siblings instead of nesting them.
  • b-for reads collection names from global config data only.
  • b-if reads the nearest b-data scope, global data, and loop metadata.
