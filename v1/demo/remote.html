r-remote

Remote HTML replaces the target content, remote JSON feeds the target scope, and a JSON view payload can carry its own html string. Detection uses the response Content-Type, so the JSON fixtures are static .json files that a normal static server sends as application/json.

A plain element in the host page is never rendered as a template, so every case below is declared inside views/demo/remote/remote-cases.html. The failure case requests a missing file on purpose, so the browser console and the network panel show the 404 while the page keeps rendering.
