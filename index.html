BitsyJS demos

Self-contained pages for every feature. Start the dev server with npm run dev and open a demo below.

b-data

Data binding

Global data, local scopes, dot paths, arrays, HTML values, and missing keys.

 b-for

For loops

Object and primitive lists, loop metadata, index conditions, empty lists, and fragments.

 b-if

Conditionals

Boolean and expression conditions, local scope values, element hiding, and loop metadata.

 b-view

Fragments

Simple and nested fragments, data-driven fragments, scoped fragments, and fragment styles.

 b-container

Containers

Wrapper unwrapping, nested containers, containers inside loops, and discarded attributes.

 bitsy.on

Events

Render listeners, the ready alias, listener order, and listeners registered after render.

 settings.tags

Custom tags

Replace all five directive tags and see why the defaults stay inactive.

 b-data

Data parsing

Scalars, nested literals, arrays of objects, string coercion, and invalid string values.

 scope

Scoping

Sibling scopes, global overrides, shallow merges, conditions, loops, and scope rules.

 b-js

Execute JS
Each demo imports BitsyJS from ./lib/bitsy.js and runs its own inline script. The demo/lib/bitsy.js file is a tiny re-export so every page can use the same import path.
