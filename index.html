Roolith JS

Demos and fixtures

One page per directive feature. Every page is static HTML plus an unbundled ES module, so open the pages through a local HTTP server instead of opening the files directly.

Demo pages

  • demo/if.html - r-if, r-else, else-if chains, and the expression evaluator.
  • demo/loop-index.html - $index, $first, $last, $length, and an indexed nested view.
  • demo/remote.html - r-remote with HTML and JSON responses, and its fallbacks.
  • demo/shadow.html - r-shadow, scoped styles, and a nested view inside a shadow root.

Remote demos need a local HTTP server, because fetch does not work from file://. For example run npx serve . or python3 -m http.server 8000 in the repository root, then open the printed URL with /demo/if.html appended. See demo/README.md.
